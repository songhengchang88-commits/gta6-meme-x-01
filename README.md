## Run it

Run the entry locally the same way the grader does:

```bash
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

To regenerate the meme image:

```bash
python3 tools/generate_meme.py
```
